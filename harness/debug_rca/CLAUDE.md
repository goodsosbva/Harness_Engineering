# debug_rca — 디버깅 / RCA 하네스

## 개요
- 진입점: debug-rca 스킬 ("BUG-001 디버깅해 줘")
- 메인 세션이 오케스트레이터
- 산출물: _workspace/bug-{id}/

## 원칙
- 재현 없이 가설 없다. 가설 없이 수정 없다
- 재현은 3회 연속 같은 결과가 나와야 인정한다 (결정론 게이트)
- 코드 수정은 fixer만 한다
- 수정-검증 루프는 최대 3회. 넘으면 사람에게 넘긴다
- 누구의 잘못인지 묻지 않는다. 시스템이 왜 그 결과를 허용했는지 묻는다
- 누구도 git commit 하지 않는다
