# Review Reply Templates

## 반영

```markdown
✅ 반영했습니다. (<커밋 해시>)

<무엇을 어떻게 바꿨는지 한두 문장>
```

## 질문 답변

```markdown
💬 <질문에 대한 답변>

<필요하면 근거가 되는 코드 위치나 문서>
```

## 반영 안 함

```markdown
🙅 이번에는 반영하지 않았습니다.

- 이유: <근거가 틀렸음 / 이 PR 범위 밖 / 트레이드오프상 현재가 나음>
- <대안이나 후속 계획. 예: 별도 이슈 #<번호>로 분리>

다른 의견이 있으시면 말씀해 주세요.
```

## 보류 (사용자 결정 대기)

```markdown
⏸️ 확인 중입니다. <무엇을 결정해야 하는지> 정해지면 다시 답변드리겠습니다.
```

## 종합 코멘트 (리뷰 본문, 일반 코멘트용)

리뷰 본문과 일반 코멘트는 답글 기능이 없으므로 PR 코멘트 하나에 모아서 답합니다.

```markdown
## 리뷰 반영 결과

<리뷰어 또는 리뷰 링크>의 리뷰를 아래와 같이 처리했습니다.

| # | 지적 | 처리 | 커밋 |
|---|---|---|---|
| 1 | <지적 요약> | ✅ 반영 | <해시> |
| 2 | <지적 요약> | 🙅 반영 안 함: <이유> | - |
| 3 | <지적 요약> | 💬 답변: <요약> | - |

### 테스트

- <실행한 명령과 결과. 실행하지 못했다면 그 이유>
```
